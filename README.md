🌱 EcoTech Solutions Website

Affordable, Sustainable Technology for South Africa

---

1. Project Overview

EcoTech Solutions is a website project developed to represent a fictional South African technology company established in 2021 in Johannesburg, South Africa.

The company focuses on providing affordable, environmentally friendly and sustainable technology solutions to students, households and small businesses.

The website aims to promote sustainable technology while providing information about the company's products, services, locations and contact details.

This project is developed in three main parts, progressing from website planning and structure to advanced styling and interactive JavaScript 3D features.

2. Project Objectives

The main objectives of the EcoTech Solutions website are to:

- Create a professional and user-friendly website.
- Promote affordable and sustainable technology.
- Display the company's products and services.
- Provide information about the company.
- Display headquarters and proposed branch locations.
- Allow customers to submit enquiries.
- Provide contact information.
- Develop a modern, futuristic and responsive design.
- Introduce interactive JavaScript functionality and 3D animations.

7. Installation and Setup

Follow these steps to run the website on your computer.

Requirements

- Visual Studio Code.
- A modern web browser such as Google Chrome, Microsoft Edge or Firefox.
- Live Server extension for Visual Studio Code.
- A local copy of the EcoTech Solutions project.

Steps to Run the Project

1. Download or clone the EcoTech Solutions project.
2. Open Visual Studio Code.
3. Select File → Open Folder.
4. Select the EcoTech Solutions project folder.
5. Check that the HTML, CSS, JavaScript and image files are in their correct locations.
6. Install the Live Server extension if it is not already installed.
7. Open "index.html".
8. Right-click inside the editor.
9. Select Open with Live Server.
10. The website should open in your default browser.

Running the Website

The homepage is:

index.html

All other pages should be accessible through the navigation menu.

8. JavaScript Setup

The main JavaScript file is:

script.js

To connect JavaScript to an HTML page, add the following line immediately before the closing "</body>" tag:

<script src="script.js"></script>

For the advanced 3D globe, the project may also use:

globe.js

If Three.js is used, its library must be loaded before the JavaScript code that depends on it.

All JavaScript file paths must match the actual project folder structure.
