# ♻️ EcoTech Solutions — Sustainable & Futuristic Web Platform

A modern, responsive, 7-page web application built with HTML5, CSS3, vanilla JavaScript, and **Three.js**. Designed with a futuristic dark-mode glassmorphic interface, interactive 3D elements, real-time form validation, and a 3D interactive holographic globe displaying South African network locations.

---

## 🌟 Key Features

* **Futuristic UI Design System**: Midnight dark palette (`#020d1a`), glassmorphic card layouts, custom neon badges, and subtle CSS grid structures.
* **3D Interactive Globe (Three.js)**: A high-tech 3D command-center globe on the **Locations** page featuring real-time orbit controls, glowing atmosphere, wireframe depth, and interactive markers for South African branches.
* **Dynamic 3D Card Tilts**: Hardware acceleration and interactive mouse-tracking card tilts across the **Products**, **Services**, and **About** pages.
* **Interactive Forms & Validation**: Real-time JavaScript validation with smooth glowing feedback notifications on the **Inquiry** and **Contact** forms without full-page reloads.
* **Fully Responsive**: Standardized navigation, flexible multi-column grid layouts, and fluid scaling across desktop, tablet, and mobile browsers.

---

## 📄 Site Structure (7 Pages)

1. `index.html` — **Home**: Hero banner, mission overview, core offerings, and CTA links.
2. `about.html` — **About**: Company history, mission, vision, and target audience breakdown.
3. `services.html` — **Services**: IT support, web development, device recycling, and refurbishment details.
4. `products.html` — **Products**: Interactive catalog displaying laptops, desktops, and eco accessories.
5. `locations.html` — **Locations**: Three.js 3D interactive globe with markers for Johannesburg (HQ), Pretoria, Durban, and Cape Town.
6. `inquiry.html` — **Inquiry**: Detailed request form with multi-option service/product selector.
7. `contact.html` — **Contact**: General contact details, direct email/phone links, and quick messaging form.

---

## 🛠️ Built With

* **HTML5**: Semantic web architecture.
* **CSS3**: Custom properties, Glassmorphism, CSS Grid, Flexbox, keyframe animations.
* **JavaScript (ES6+)**: DOM manipulation, interactive form handler, custom tilt math.
* **Three.js (r128)**: 3D scene rendering, WebGL lighting, OrbitControls, matrix position calculations.
