EcoTech Solutions Website

Overview

EcoTech Solutions is a website project developed for a fictional South African technology company that provides affordable and environmentally friendly technology solutions.

The website is designed to give customers information about the company, its services, products, locations and contact details. It also provides an inquiry form that allows potential customers to submit questions about products and services.

The website is designed to be simple, user-friendly and responsive on different screen sizes.

Main Website Sections

- Home – Introduction to EcoTech Solutions and its mission.
- About – Company history, mission, vision and target audience.
- Services – Information about IT support, website development, device recycling and computer refurbishment.
- Products – Information about refurbished laptops, desktops, eco accessories and eco-friendly electronics.
- Locations – Head office in Johannesburg and proposed branches in Pretoria, Durban and Cape Town.
- Inquiry – Customer inquiry form for products and services.
- Contact – Company email, telephone number, head office and business hours.

«Note: The company, contact details and branch locations are fictional/proposed information created for the school project.»

Tech Stack and Requirements

Technologies Used

- HTML5 – Used to create the structure and content of each webpage.
- CSS3 – Used to style the website, including colours, typography, navigation, forms, spacing and responsive design.
- Visual Studio Code – Used as the main development environment.
- GitHub – Recommended for storing, managing and submitting the project repository.

Software Requirements

To run and edit the project, you need:

1. A computer with Windows, macOS or Linux.
2. Visual Studio Code or another code editor.
3. A modern web browser such as:
   - Google Chrome
   - Microsoft Edge
   - Mozilla Firefox
4. An internet connection is recommended for downloading Visual Studio Code or GitHub tools, but the website itself does not require an internet connection to run locally.

Optional Requirement

Live Server can be installed as a Visual Studio Code extension. It allows the website to be opened through a local development server and automatically refreshes the webpage when changes are made.
